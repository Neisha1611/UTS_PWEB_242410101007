# 🌿 Velora - Fashion Management Website

Velora adalah website berbasis Laravel yang digunakan untuk membantu pengguna dalam mengelola koleksi fashion secara sederhana dan terstruktur.

Website ini dirancang dengan tampilan yang clean dan mudah digunakan, sehingga pengguna dapat melihat dan mengatur data produk dengan lebih efisien.

## ✨ Fitur Utama

- 🔐 **Login System**  
  Sistem login dengan validasi input untuk memastikan keamanan akses pengguna.

- 📊 **Dashboard**  
  Menampilkan ringkasan data seperti jumlah koleksi, kategori, penjualan, dan produk terlaris.

- 👤 **Profil Pengguna**  
  Menampilkan informasi pengguna beserta aktivitas terbaru.

- 📦 **Pengelolaan Koleksi**  
  Menampilkan data produk fashion seperti:
  - Nama produk  
  - Kategori  
  - Ukuran  
  - Harga  
  - Stok  
  - Status ketersediaan  

## 🛠️ Teknologi yang Digunakan

- Laravel  
- Blade Template  
- HTML  
- CSS  
- JavaScript
